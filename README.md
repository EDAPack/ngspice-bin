# ngspice-bin

[ngspice](https://ngspice.sourceforge.io/), the mixed-level/mixed-signal circuit simulator, as a portable pre-built package for [edapack](https://dvkit.org/edapack/).

**Documentation:** https://dvkit.org/edapack/ngspice-bin/

Releases, with one tarball per platform: https://github.com/EDAPack/ngspice-bin/releases

Install it with [IVPM](https://github.com/fvutils/ivpm):

```yaml
- name: ngspice-bin
  url: https://github.com/edapack/ngspice-bin
  src: gh-rls
```
